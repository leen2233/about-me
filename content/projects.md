### Flickture
**Description:**  
A watchlist platform for movies and TV shows. Like Trakt.tv, Letterboxd, etc.

**Tech Stack:**  
- **Backend**
    - Python / Django
    - Postgresql
- **Web**
    - React
- **Mobile**
    - React Native
- **External**
    - TMDB Data API

**Key Features:**  
- Add, Delete movies and TV shows to watchlist, mark as watched
- Write public comments, give a review to movies
- Follow / unfollow user, and see their actions in Feed page.

**Links:**    
- **Backend**: https://github.com/leen2233/flickture
- **Web**:         https://github.com/leen2233/flickture-web
- **Mobile**:    https://github.com/leen2233/flickture-mobile
